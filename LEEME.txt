TALLERES LA PAZ 99 — DEMO PRIVADA
=================================

1. Extrae el ZIP completo.
2. Abre index.html con Chrome, Edge o Firefox. No necesita servidor ni instalación.
3. También puedes abrir la carpeta en VS Code y usar Live Server.

Archivos: index.html (estructura), style.css (diseño responsive), script.js
(interacción), assets/ (ilustración y marca gráfica provisional en SVG).
No usa librerías externas, cookies de seguimiento, base de datos ni backend.
La solicitud de cita se simula en local y no envía información.
